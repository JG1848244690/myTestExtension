一键快捷键,把当前页面加为书签。预设全局快捷键 Ctrl + Y(Windows)或 Command + Y(Mac),popup 直接打开到"快捷添加"标签页。当前网址已自动填好,你只需输入名称,可选一个分组,回车保存。无需切换上下文、无需复制粘贴、无需多余点击。在 popup 里按 Ctrl + 1 到 Ctrl + 5,前五个匹配的快捷方式直接打开,常用网站从 Chrome 任何位置都一键直达。

保存并跨设备恢复多标签页。会话标签页把当前所有打开的标签打包成一个快照,你可以给它命名,一键就能整套还原。登录 Google 账号后,会话自动同步到云端,昨晚在笔记本上没看完的资料,今早打开 popup 就已经在桌面端等你。本地会话先存本机,云同步完全可选,随时可手动上传或下载。

打开新标签页你能得到什么。分组书签与收藏,布局完全由你掌控。拖拽排序、批量管理、为分组染色,重要的内容一眼可见。Google / 必应 / 百度三选一的即时搜索,带搜索建议与本地历史记录,所有操作在设备本地完成。背景随心情切换:从纯色预设、精选壁纸里挑一张,或上传自己的图片。一键从 Chrome 书签栏导入,或导出 JSON 文件备份还原。可选云同步让书签跨设备随身带,不登录也能完整使用。

默认隐私优先。书签、搜索历史、会话、设置全部保存在本地,云同步完全可选,使用扩展无需注册账号。无广告、无追踪、无统计指纹、无第三方数据共享。纯暗色 UI 日间夜间都舒适,壁纸透明度可调,任何背景都能保证可读性。
